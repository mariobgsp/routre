Stop paying for tokens you already sent.

routre is one small program on your computer that sits between your AI tools and your AI providers. It shortens repeated tool output before you are billed, reuses an answer it has already seen, and switches provider automatically when one is busy.

What it does

Three things, all local, all automatic once it is running.

Pay less

Long tool output — file listings, logs, search results — is shortened before it is sent. An identical request is answered from a local cache instead of the provider, so you are not billed twice.

Stay online

If a provider is overloaded or down, routre tries the next one on its own. Your tool keeps working instead of showing an error.

See what you spend

Every request is counted per agent, with tokens and estimated cost. routre list prints the ledger; the local dashboard shows the same numbers in a browser.

The compression step is called RTK. It is on by default and needs no configuration. How a request is handled ↓

Install

macOS and Linux, one line. It downloads the latest release, verifies its checksum and installs to ~/.local/bin.

curl -fsSL https://raw.githubusercontent.com/mariobgsp/routre/main/install.sh | sh

Check it: routre version

Other ways to install

Windows. Download routre_windows_amd64.zip from Releases, unzip it into a folder such as %USERPROFILE%\routre, add that folder to your user PATH, then run routre version. No admin rights or installer.

From source. Needs Go 1.22 or newer:

git clone https://github.com/mariobgsp/routre
cd routre
make build

Use it in 3 steps

About two minutes the first time.

  1. Configure your providers

    A short wizard asks for your providers, their URLs and your API keys. It writes config.json and a private routre.env (mode 0600) next to it.

    routre setup

  2. Start the gateway

    It listens on 127.0.0.1:20128. Use routre start --autostart instead to run it in the background and bring it back after a reboot.

    routre serve

  3. Point your tool at it

    Claude Code uses ANTHROPIC_BASE_URL; Codex, opencode, Cursor and most OpenAI-compatible tools use OPENAI_BASE_URL. Set the one your tool reads, then restart it.

    export OPENAI_BASE_URL=http://127.0.0.1:20128
export ANTHROPIC_BASE_URL=http://127.0.0.1:20128

Check it is up: curl http://127.0.0.1:20128/healthz prints ok. Add or replace keys, and edit the whole config, in the browser at http://127.0.0.1:20128/ui — loopback only.

What happens to a request

Everything below happens on your machine, in this order.

  1. Compress. Repetitive tool output is shortened. If the result would not be smaller, the original is sent unchanged.
  2. Cache. The processed request is hashed. An identical earlier request is replayed locally, with no provider call at all.
  3. Route. Providers are tried in the order you configured, usually cheap first. A provider that just failed is skipped for a short cooldown.
  4. Fail over. A busy or failing provider is dropped and the next one is tried. A slow but healthy provider is given a little longer before moving on.
  5. Relay. The answer streams back to your tool in the dialect it expects, even when the provider speaks a different API.

Questions

Short answers, no marketing.

Does my code leave my machine?

Only in the request you already send to your AI provider, and only to that provider. routre listens on 127.0.0.1, so it is reachable from your own computer and not from the network. Its cache and ledger live under ~/.routre.

Do I need Node, Python, Postgres or Redis?

No. routre is one static binary. It manages its own JSON config, its on-disk cache and its token ledger. There is no runtime, database or message broker to install or babysit.

What happens when a provider is down or busy?

routre retries once, refreshes an expired key if it can, then moves to the next provider in your order. A provider that fails is cooled down for a short while so it is not hammered, and a provider that is merely slow is given a bounded extension before failover.

Will it work with my tool?

If the tool speaks the OpenAI or Anthropic HTTP API, yes: Claude Code, Codex, opencode, Cursor and most others. Point its base URL at http://127.0.0.1:20128. When the client and the provider speak different dialects, routre translates the stream in flight.

Does it cost anything?

routre is MIT-licensed open source with no paid tier. You still pay your providers for the tokens you use. routre's job is to send fewer of them and to keep working when one provider fails.

What does it not do?

It does not change your prompts or the model's answers, and it only compresses tool results — output tokens are never compressed, so your savings depend on how tool-heavy your work is. Token and cost figures in the ledger are estimates, not billing records.
