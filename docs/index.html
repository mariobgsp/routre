Install

curl -fsSL https://raw.githubusercontent.com/mariobgsp/routre-cli/main/install.sh | sh
routre-cli version
routre-cli setup --detect   # writes config.json + routre-cli.env (0600)
routre-cli serve            # gateway on 127.0.0.1:20128

# point any agent at it:
export OPENAI_BASE_URL=http://127.0.0.1:20128

Self-update built in: routre-cli update verifies sha256 and atomically replaces the binary. npm distribution is deprecated.
